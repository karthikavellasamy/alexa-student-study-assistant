# Alexa+ Student Study Assistant

## About the Project
Alexa+ Student Study Assistant is a student-focused web application prototype designed to help students organize their daily study tasks and track their progress.

This project demonstrates a simulated assistant experience for student productivity.

## Features
- Add and manage daily study tasks
- Mark tasks as completed
- Track task completion progress
- Filter tasks
- View simulated study tips and schedule suggestions
- Simple, responsive dashboard interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies are required for the basic simulation.

## Live Demo
https://karthikavellasamy.github.io/alexa-student-study-assistant/

## Important Note
This is an independent simulated prototype. It is not connected to the real Alexa+ service and does not use a live AI assistant.
